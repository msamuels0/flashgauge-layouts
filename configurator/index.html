Overview

The layout studio builds everything your FlashGauge shows and saves it as one .fglayout file. It runs in your browser; nothing is uploaded anywhere.

  1. Build the layout on the Build tab.
  2. Simulate it on the Simulate tab to check that it behaves the way you expect.
  3. Export one .fglayout file.
  4. Install it from the FlashGauge app's Update tab.

The dial on the left is a true-size preview of the 720 × 720 round screen. Anything outside the circle never shows on the dash. The gauge under the dial shows how much of the dash's 4 MB layout space you're using and roughly how long the install will take.

The best strategy: paint it into the background

Anything that never changes belongs in the background photo, not in a separate element. Make elements only for things that move, light up or show a changing number.

  • The background costs the same however busy it is. It's always one 720 × 720 image, about 1 MB on the dash, and it's sent compressed, so it installs in seconds. Tick marks, numbers and logos painted into it are free.
  • Every element costs extra. Images with transparency are stored and sent uncompressed at 4 bytes per pixel: a 200 × 200 lamp is about 160 KB. Each one adds install time and takes a share of the dash's 4 MB.
  • Elements slow redraws. When a needle moves, the dash redraws everything it passes over. Every static image or label stacked in that area is one more layer to redraw each frame; painted into the background, it adds nothing.
  • There are hard limits. A layout can hold 32 elements, 24 of which can react to signals, and 8 custom font files.

Two tricks that save the most:

  • Lamps: paint the dark, unlit version of each lamp into the background. Then the element is just the small lit version, set to show and hide. When it's off, the background shows through.
  • Crop tightly: trim lamp and needle images right to their edges before choosing them. Every transparent pixel around the artwork is still stored and sent.

To line things up, design the background in your image editor on a 720 × 720 canvas with a circle drawn as a guide. The studio measures element positions from the centre, so a spot at (500, 300) in your editor is X = 140, Y = −60 in the studio.

Build tab

Work down the page from top to bottom; each section feeds the next.

  1. Start from a layout. Choose Open a .fglayout to change a layout you already have, or Start a blank layout. Give it a name; the name becomes the export's file name. Pick your units for speed and distance, temperature, and the clock. Every speed, distance and temperature reading in the layout follows these.
  2. Background. Choose a photo. It goes into the layout straight away. Drag on the dial to move it and scroll (or use the Zoom slider) to size it. It always covers the whole screen, so you can't leave a black edge. Remove takes it out again.
  3. Elements. Add what needs to move or change: Needle, Label, Image, Bar or Shape. Click an element on the dial or in the list to select it. Drag it to place it, nudge it with the arrow keys (Shift moves 10), and press Delete to remove it.
  4. Selected element. Set how the element looks and, under Reacts to, which signal drives it:
    • Needle: Choose image for your own needle (a narrow PNG with a transparent background). Set Pivot in image to the pixel it turns around, then set the start and end values and angles. Drag the Test sweep slider to watch the tip trace your dial and check the pivot.
    • Label: type the text, pick a font and colour, then choose shows a number and a signal for live readouts. Suffix "auto" adds the unit (mph, °F and so on). Hide when off hides the label while a flag is off, such as a temperature with no sender fitted.
    • Image: Choose image for a lamp or icon, then set Behaviour to shows / hides and pick the lamp's signal.
    • Bar: pick a signal and the values for empty and full.
    • Rarely needed fine-tuning (smoothing, deadband, paint order) is under More settings.
  5. Fonts (optional). Two fonts are built in: montserrat_42 and montserrat_48. For another, choose a .ttf or .otf file and add the pixel sizes you want, then pick one in a label's Font field. Each size only carries the characters its labels can show, so keep to a few sizes.
  6. Send it to the dash. Press Export layout. If anything would stop the layout working on the dash, the export is held back and the problem is listed. Each export raises the revision number by one. What's in it lists every file and its size.

Simulate tab

Simulate plays your layout the way the dash will, before you install it. It uses the same update rate, needle smoothing, startup sweep and label formatting as the dash, in your layout's units. Nothing you do here is saved or exported, and the dial can't be edited until you go back to Build.

Scripted runs (the buttons at the top):

  • Key on: the needles do their startup sweep and the warning lamps light for a moment, like a bulb check.
  • Ride: about 30 seconds from a standstill up to highway speed and back, shifting through the gears. It includes a left blinker pulling away, high beam while cruising, and a right blinker before stopping. It repeats until you stop it.
  • Warm-up: the engine idles while the oil temperature climbs.
  • Pause freezes whatever is running; press it again to resume.

Manual controls (below the buttons):

  • Engine & road: RPM and speed sliders.
  • Lamps: click a lamp to switch it on or off. The blinkers can also be set to flash at the dash's own rate.
  • Distance, temperature, clock: type an odometer or trip value, slide the temperatures, and set the clock (or use this computer's time).

Touching any control stops a scripted run so you can take over. Controls shown faded aren't used by your layout, so you can see at a glance which signals your layout reacts to.

What to check: needles reach the right marks at your redline and top speed, lamps sit over their painted "off" icons, and numbers fit their space at their widest (for example 188.8 or 12:59 PM).

Installing, and vehicle settings

Move the exported .fglayout file to your phone, open the FlashGauge app, and choose the file in the Update tab. The dash holds one layout at a time, so installing a layout replaces the old one. Your odometer and vehicle settings are kept. If an install is interrupted, the dash shows its built-in layout until you install again.

To change a layout later, open the same .fglayout in the studio, make your changes and export again. The new file has the next revision number.

Vehicle settings (the last section on the Build tab) are the per-bike numbers that make the readings correct. They're stored with the bike's wiring adapter, not the layout, so they survive layout changes.

What you can change depends on your adapter. With the universal adapter you set everything below. A bike-specific adapter already knows its bike: you can change what varies from bike to bike, such as tire size, but fixed values such as tach pulses (set by the number of cylinders) stay locked.

  • Pulses: tach pulses per crank turn (set by the number of cylinders), and speed-sensor pulses per wheel turn.
  • Wheel: rolling circumference in mm. Type a tire size (such as 180/55-17) for an estimate; measuring a roll-out is more accurate.
  • Temperature curves: sender reading against temperature for oil and coolant. Generate from an NTC sender fills one in from the sender's datasheet values. A curve left empty hides that reading.

Choose Start from defaults (or open an existing vehicle.json), fill it in and press Export vehicle.json. In the app, go to the Vehicle tab, choose Import file, then Save to dash.

  • Speed and distance count in tenths. A needle that should reach 160 mph at the end of its sweep needs a Value at end of 1600. The signal list shows this as "speed (0.1 mph)".
  • Drag and drop works. Drop a .fglayout to open it, a photo to make it the background, a font file to add it under Fonts, or a vehicle.json to load it into Vehicle settings.
  • Each blinker gets its own image. Choosing an image for one element never changes another, even if they started with the same built-in artwork.
  • Watch the warnings at export. A warning such as a label whose font is missing a character won't block the export, but it means something will look wrong on the dash.

Start from a layout

Load a dash.json to keep working on it — everything it contains is kept, even fields this tool doesn't edit — or start blank and build the whole layout here.

Opening a .fglayout unpacks it — the layout, its artwork and its fonts — so you can change one thing and export it again. It keeps the original layout's identity; use Remix as my own if you're publishing it as a new layout rather than updating that one.

Units

The dash converts every signal once, so speed, distance and temperature labels and needle ranges are all in these units.

Elements

Everything the dash draws. Add widgets here, then click one on the dial or in this list to select it — drag to place, arrow keys nudge (Shift = 10), Delete removes.

Background

Drag to move, scroll or use the slider to zoom. Only what falls inside the circle is visible on the dash, so frame it against the round edge.

Fonts

Add a TrueType or OpenType font, then the sizes you want. Each size becomes its own font file on the dash, holding only the characters its labels can show, so a big speedo font stays small. Use one by typing its name into a label's Font field; the files rebuild themselves as you change those labels.
